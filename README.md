# بورتفوليو أميرة عبد الرازق

موقع React عربي باتجاه RTL، وصفحة مستقلة للأعمال والمشاريع.

## المكوّنات والتواصل

- كل قسم في الرئيسية، والرأس والفوتر، مكوّن مستقل داخل `src/components/`.
- الصفحات داخل `src/pages/`، وصفحة الأعمال مستقلة عن الرئيسية.
- عدّلي رقم واتساب والروابط الاجتماعية في `src/data/siteConfig.js`.
- لكل مشروع صورة فوتوغرافية ومصدرها في `src/data/projects.js`، وتُحمّل الصور من Unsplash عند الاتصال بالإنترنت.
- أيقونات مواقع التواصل في الفوتر من مكتبة `react-icons`.
- الرقم الحالي مضبوط على `201123357185`، ويمكن تغييره من ملف الإعدادات.

## التشغيل

```bash
npm install
npm run dev
```

## إضافة أو تعديل عمل

افتحي `src/data/projects.js` وأضيفي عنصراً جديداً داخل مصفوفة `projects`:

```js
{
  id: 'عنوان-بالإنجليزية-أو-العربية',
  type: 'مقال', // مقال، ملخص كتاب، محتوى تسويقي، منشور اجتماعي
  category: 'تطوير ذاتي',
  title: 'عنوان العمل',
  excerpt: 'نبذة قصيرة تظهر في بطاقة العمل.',
  readTime: '٤ دقائق',
  featured: false, // true لإظهاره ضمن الأعمال المختارة في الرئيسية
  number: '07',
  body: 'نص العمل هنا.\n\nافصلي بين الفقرات بسطرين.'
}
```

تُنشأ بطاقة العمل وصفحته تلقائياً. النصوص الموجودة حالياً نماذج تحريرية أولية، ويمكن استبدالها بأعمال أميرة المنشورة أو المعتمدة.
